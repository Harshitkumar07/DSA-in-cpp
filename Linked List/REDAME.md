## Overview

This folder contains a collection of solutions to a wide range of coding problems centered around **Linked Lists** in C++. Linked Lists are a fundamental data structure used to organize data dynamically with flexible memory allocation. They are essential for mastering data structures and algorithms, coding interviews, and competitive programming.

The problems in this repository are sourced from popular coding platforms like **GeeksforGeeks (GFG)**, **Leetcode**, and others. Each solution is carefully structured to help you understand and implement efficient algorithms. Whether you're learning about linked lists for the first time or aiming to refine your skills, this repository provides a comprehensive resource.

---

## Structure

Each problem is implemented with the following structure:
- **Problem**: Problem statement.
- **Example Input and Output**: Example input and output of the problem statement.
- **Solution**: Exact code to solve the problem.
- **C++ Code**: The C++ implementation of all solutions.
- **Time & Space Complexity**: A breakdown of the time and space complexity for the recursive solution.
- **Best and Worst Time Complexity**: Also provides best and worst time complexities of implemented code.
- **Example Input and Output**: Example of input and output that shows how it looks like after compilation.

---

## How to Use

1. Clone this repository.
2. Navigate to the `Linked List/` folder.
3. Each file contains a problem solution. You can directly copy-paste the solution to GeeksforGeeks or Leetcode.
